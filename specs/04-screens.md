# 04. 화면 구성

> Vue 3 SPA + Bootstrap 5.0(CSS만) + Chart.js. `[A-xx]`는 `99-assumptions.md` 참조.
> 모든 화면 문구는 한국어, 데스크톱 우선 [A-44].

## 1. 라우팅 (Vue Router) [A-38]

| 경로 | 화면 | 접근 |
|---|---|---|
| `/login` | 로그인 | 공개 |
| `/entry` | 월 실적 입력 | 직원 |
| `/admin/dashboard` | 누적 대시보드 | 관리자 |
| `/admin/report` | 월별 리포트 | 관리자 |
| `/admin/status` | 입력 현황 | 관리자 |
| `/admin/goals` | 연간 목표 | 관리자 |
| `/admin/users` | 사용자 관리 | 관리자 |
| `/admin/departments` | 부서·입력 항목 관리 | 관리자 |

- 로그인 후 이동: 직원 → `/entry`, 관리자 → `/admin/dashboard`
- 라우트 가드: 미로그인 → `/login`. 역할 불일치 → 자기 홈으로 이동 (실제 통제는 서버 [NFR-03])
- API 401 응답 시 토큰을 지우고 `/login`으로 이동

## 2. 공통 레이아웃

- 상단 내비게이션 바: 서비스명 “경영지표 대시보드”, 메뉴(역할별), 우측에 `성명 (부서/관리자)` + 로그아웃
- 직원 메뉴: 월 실적 입력
- 관리자 메뉴: 대시보드 / 월별 리포트 / 입력 현황 / 연간 목표 / 사용자 / 부서·항목
- 알림은 Bootstrap alert 스타일 인라인 메시지(저장 성공, 오류)로 표시. 별도 토스트/모달 라이브러리 없음 [A-38]
- 계산 불가 값은 `-` 표시, 금액은 천 단위 콤마 [A-36]

## 3. 화면 상세

### 3.1 로그인 `/login` [FR-E01, A-10]
- 입력: 성명, 사번, 비밀번호 → `로그인` 버튼
- 실패: “성명, 사번 또는 비밀번호가 올바르지 않습니다.” (어느 값이 틀렸는지 구분하지 않음)

### 3.2 월 실적 입력 `/entry` (직원) [FR-E02 ~ E08]

```
┌ 연도/월 선택 [2026 ▼][9월 ▼]     부서: 생산     상태: 작성 중 ┐
│ ▓▓▓▓▓▓░░░░ 입력 진행률 50% (3/6 필수 항목)                      │
│ ⓘ 부서 안내 문구(input_guide)                                   │
│ ───────────────────────────────────────────────────────────── │
│ [월 합계형 항목]  항목명 (단위) ★필수       [ 입력 칸 ]         │
│                   ↳ 항목 안내 문구(help_text)                   │
│ [프로젝트별형]    항목명 (단위) ★필수                            │
│                   프로젝트명 [      ]  값 [      ]  [삭제]      │
│                   [+ 프로젝트 행 추가]                           │
│ ───────────────────────────────────────────────────────────── │
│ 엑셀/CSV 업로드: [파일 선택] [업로드]  (열: 항목명, 프로젝트명, 값)│
│                                    [임시 저장]  [제출]           │
└──────────────────────────────────────────────────────────────┘
```
- 월 선택: 현재 월 이하만 선택 가능, 기본 현재 월 [A-17]
- 진행률 막대는 입력 중 실시간 갱신(서버 계산 규칙과 동일 [A-20]), 저장/불러오기 시 서버 값과 일치
- **입력 방법 안내 문구**: 폼 상단(`input_guide`)과 각 항목 아래(`help_text`) [A-08]
- 숫자 입력 칸: 숫자만 허용, 소수 허용
- 프로젝트별형: 행 추가/삭제 가능. 프로젝트명은 항목마다 자유 입력 [A-04]
- `임시 저장`: PUT. 성공 시 “임시 저장되었습니다.”
- `제출`: 제출 전 확인 대화(브라우저 기본 `confirm`). 필수 항목 미입력이면 미입력 항목을 목록으로 안내(서버 `incomplete_required`)
- 상태별 동작
  - 미작성/작성 중: 편집·업로드·저장·제출 가능
  - **제출 완료**: 전 입력 칸·버튼 비활성화, “제출 완료 (제출일시)” 표시. 재제출 시도는 409 메시지 [A-18]
- 업로드 성공 시 폼에 값이 채워지고 “n건 반영됨, 확인 후 제출하세요” 표시. 실패 시 행별 오류 목록 표시 [A-24]
- 부서가 없는 직원 계정으로 로그인하면 “소속 부서가 없습니다. 관리자에게 문의하세요.” 표시

### 3.3 누적 대시보드 `/admin/dashboard` [FR-A07, FR-A09]

- 상단 컨트롤: 연도, 기준 월, 자금 예측 기간(3~6개월), `CSV 다운로드`
- `data_status.has_warning`이면 상단에 “일부 부서 미제출: 구매/자재, 경영지원 (제출된 데이터만 집계)” 경고 [A-25]
- 구성 (위에서 아래, 카드/차트):

| 섹션 | 표시 | Chart.js 차트 |
|---|---|---|
| KPI 요약 카드 | 누적 매출액, 영업이익, 영업이익률, 가동률, BEP 달성률, 인당 매출액 | — |
| 종합 원가/이익률 | 매출·원가 구성·이익·이익률 표 | 월별 매출/영업이익(막대) + 영업이익률(선) |
| 프로젝트별 원가/이익률 | 프로젝트 표(매출, 총원가, 매출총이익, 이익률) | 프로젝트별 매출·원가(가로 막대) |
| 매입·매출·미수금 | 누적 매출, 매입, 수금, 미수금 잔액, 미수금 비율 | 월별 매출·매입(막대) + 미수금 잔액(선) |
| 자금 수지 예측 | 예측 표(유입, 유출, 순현금흐름, 예상 잔액), 자금 부족 예상 월 강조 | 실적 + 예측 현금 잔액(선) |
| BEP | BEP 매출액, 현재 매출, 달성률 | 진행 막대 또는 단일 막대 |
| 생산량·가동률 | 누적 생산량, 생산 능력, 가동률 | 월별 생산량(막대) + 가동률(선) |
| 수주 잔고·파이프라인 | 수주 잔고, 신규 수주, 파이프라인, 가중 파이프라인 | 월별 수주 잔고(선) 또는 막대 |
| 인당 생산성 | 인당 매출·영업이익·생산량 | 월별 인당 매출(선) |
| 목표 대비 달성률 | 지표별 목표/실적/달성률 | 달성률 가로 막대(100% 기준선) |

- 차트는 Chart.js 직접 사용 [A-38]. 색상은 Bootstrap 기본 색상 계열로 통일

### 3.4 월별 리포트 `/admin/report` [FR-A08, FR-A09]
- 컨트롤: 연도, 월, 예측 기간, `CSV 다운로드`
- 대시보드와 같은 8개 분석 항목을 **표 중심**으로 표시하며 각 지표에 `당월` / `누적` 두 열을 병기
- 차트는 자금 수지 예측, 프로젝트별 원가/이익률 2개만 표시(나머지는 표)
- 미제출 경고는 대시보드와 동일

### 3.5 입력 현황 `/admin/status` [FR-A06, A-19, A-22]
- 컨트롤: 연도, 월
- **요약 탭**
  - 상단: “제출 2/4 부서 (50%)” 진행 막대
  - 부서별 표: 부서, 상태 배지(미작성/작성 중/제출 완료), 진행률, 제출자, 제출일시, [상세 보기]
  - **미제출 모니터링**: 미제출 부서 목록을 강조 박스로 표시
  - 연간 월×부서 현황표(1~12월 × 부서, 상태 색상 셀)
- **상세 화면**(부서 [상세 보기] 클릭)
  - 해당 부서·월 입력값을 **읽기 전용**으로 표시(항목, 프로젝트명, 값, 단위)
  - 제출 완료 상태이면 `초안으로 되돌리기` 버튼(확인 대화 후 reopen) [A-19]

### 3.6 연간 목표 `/admin/goals` [FR-A05, A-35]
- 연도 선택 → 지표 5개(매출액, 영업이익률, 가동률, 생산량, 신규 수주액)의 목표값 입력 표 + `저장`
- 값을 비우고 저장하면 목표 삭제(“목표 미설정”)
- 각 행에 단위(원/%/개) 표시. 현재 누적 실적 참고 표시는 하지 않는다(대시보드에서 확인)

### 3.7 사용자 관리 `/admin/users` [FR-A02]
- 사용자 표: 성명, 사번, 역할, 부서, 활성 여부, [수정] [삭제]
- `+ 사용자 추가` / 수정: 성명, 사번, 역할(직원/관리자), 부서(직원 필수), 비밀번호(추가 시 필수, 수정 시 입력하면 재설정), 활성 여부
- 삭제: 확인 대화 후 실행. 자기 자신/마지막 관리자는 오류 메시지 [A-15]
- 화면 상단에 “기본 관리자(ADMIN)의 초기 비밀번호는 변경하세요.” 안내 [A-13]

### 3.8 부서·입력 항목 관리 `/admin/departments` [FR-A03, FR-A04]
- 좌측: 부서 목록 + `+ 부서 추가` (이름, 입력 안내 문구, 순서, 삭제)
- 우측: 선택한 부서의 입력 항목 표(이름, 범위, 단위, 지표 연동 키, 필수, 순서, [수정] [삭제]) + `+ 항목 추가`
- 항목 폼 필드: 항목명, 범위(월 합계형/프로젝트별형), 단위, 지표 연동 키(선택 드롭다운 [A-07]), 필수 여부, 안내 문구, 순서
- 삭제 시 “과거 제출 데이터는 유지됩니다” 안내 [A-06]
- 이미 값이 입력된 항목의 `범위` 변경은 막고 안내한다(서버 400)

## 4. 컴포넌트 지침

- 페이지 단위 컴포넌트(`views/`)와 재사용 컴포넌트(`components/`) 분리
- API 호출은 `api/` 모듈(fetch 래퍼)로 모으고 컴포넌트에서 직접 fetch 하지 않는다
- 계산 로직을 프런트에 두지 않는다 (진행률 실시간 표시만 예외 [A-20])
