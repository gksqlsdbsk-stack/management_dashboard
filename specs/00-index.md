## 우선순위 규칙

1. `99-assumptions.md`의 내용이 다른 specs 문서의 같은 값과 다르면 **99가 우선**한다 (사용자가 수정한 값이므로). 다른 문서는 99에 맞춰 갱신한다.
2. 그 외 문서 간 충돌은 구현을 멈추고 사용자에게 확인한다.
3. 문서에 없는 값·기능이 필요해지면 임의로 정하지 않고, 임시로 정한 경우 반드시 99에 `A-xx`로 추가한다.

## 표기 규칙

- `[A-xx]`: 99-assumptions.md의 항목 참조
- `FR-E##` / `FR-A##`: 직원/관리자 기능 요구 ID (01)
- `NFR-##`: 비기능 요구 ID (01)
- 보고서 상태값: `DRAFT`, `SUBMITTED` (화면 전용 `NOT_STARTED` = 레코드 없음)
